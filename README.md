## Сайт

Статический многостраничный сайт с 10 направлениями продукции, разделами российской техники, услуг, заказчиков, компании, проектов, документов и контактов. HTML генерируется заранее; содержание доступно без JavaScript. Шрифты и изображения размещены локально.

Формы отправляются через FormSubmit на `tender@ligus-msk.ru`. Поддерживается вложение до 10 МБ. Владелец подтвердил подключение почты; FormSubmit принял тестовую заявку после активации 15 сентября 2026 года. Серверный код и ключи API в репозитории отсутствуют. reCAPTCHA сервиса не отключается.

Проекты демонстрационные, юридические реквизиты ещё не заполнены. Пока сайт сохраняет `noindex`; аналитика и рекламные кампании не подключены.

## Просмотр локально

Требуется Python 3.12 или новее.

```sh
python3 build.py
python3 verify.py
python3 -m http.server 4187 --bind 127.0.0.1 --directory dist
```

Откройте `http://127.0.0.1:4187/`.

## Публикация

GitHub Actions публикует сайт на GitHub Pages при каждом push в `main`. В Settings → Pages выбран источник GitHub Actions. Workflow получает адрес и префикс из настроек Pages: ссылки работают как по адресу проекта, так и после подключения собственного домена.

- `build.py`: содержимое и генератор страниц.
- `site.json`: основные сведения и обработчик формы.
- `dist/`: локальный сайт, стили, JavaScript и статические ресурсы.
- `verify.py`: заголовки, метаданные, ссылки и якоря.
- `.github/workflows/pages.yml`: автоматическая сборка и публикация.

Пример отдельной сборки для адреса проекта:

```sh
OUTPUT_DIR=_site BASE_PATH=/ligus-msk SITE_URL=https://aleshaio.github.io/ligus-msk python3 build.py
OUTPUT_DIR=_site BASE_PATH=/ligus-msk python3 verify.py
```

## Домен

DNS домена обслуживается Reg.ru. Перед переключением задайте `ligus-msk.ru` в Settings → Pages → Custom domain, затем направьте A-записи корня домена на адреса GitHub Pages:

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

Для `www` можно добавить CNAME на `aleshaio.github.io`. Не изменяйте MX, SPF, DKIM и другие записи почты. После обновления DNS дождитесь сертификата, включите Enforce HTTPS и повторно запустите workflow публикации. Обновите `domain` в `site.json` на `https://ligus-msk.ru` после проверки HTTPS.

[Документация GitHub Pages](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) · [FormSubmit](https://formsubmit.co/documentation)

## Графика

Логотип — самостоятельный SVG с прозрачным фоном, нарисованными кириллическими буквами и сквозными каналами. Он выполнен по типографическому референсу заказчика, в ультрамарине и без знака TM. Иллюстрации оборудования и первого экрана созданы с помощью ImageGen. Фотография оборудования иллюстративная и не подтверждает ассортимент или включение моделей в реестр.

Обложка для ссылок находится в `dist/og.png`. Общие Open Graph и Twitter Card метаданные добавляются генератором на все страницы; заголовок и описание соответствуют каждой странице. Абсолютный адрес изображения строится из `SITE_URL`, размеры считываются из PNG, а хеш файла в URL обновляет адрес при замене обложки. Для новой обложки замените PNG и запустите сборку. В `robots.txt` разрешён обход роботам превью; `noindex` для поисковых систем сохранён.

Шрифт Manrope используется по SIL Open Font License, копия лицензии находится в `dist/assets/OFL-Manrope.txt`.
