# Лигус

Корпоративный сайт поставщика компьютерной техники, электроники и бытового оборудования. География: вся Россия и страны СНГ.

- Телефон: +7 977 977 22 31
- Email: tender@ligus-msk.ru
- Основной сайт: https://ligus-msk.ru/ (REG.RU, HTTPS и SMTP работают)
- GitHub Pages: https://aleshaio.github.io/ligus-msk/

## Сайт

Статический многостраничный сайт с 10 направлениями продукции, разделами российской техники, услуг, заказчиков, компании, проектов, документов и контактов. HTML генерируется заранее; содержание доступно без JavaScript. Шрифты и изображения размещены локально.

В копии на GitHub Pages формы отправляются через FormSubmit на `tender@ligus-msk.ru`. Поддерживается вложение до 10 МБ. Владелец подтвердил подключение почты; FormSubmit принял тестовую заявку после активации 15 сентября 2026 года. Ключей API и SMTP-паролей в репозитории нет. reCAPTCHA сервиса не отключается.

На REG.RU загружен сайт с собственным PHP-обработчиком для SMTP: [инструкция и требования к хостингу](docs/smtp-hosting.md). На ligus-msk.ru включена отправка через SMTP Mail.ru; получение тестового письма и вложения подтверждено владельцем. Копия на GitHub Pages сохраняет FormSubmit. [Состояние размещения](docs/deployment.md). Команда `python3 scripts/build_hosting.py` создаёт `release/ligus-hosting.zip` с формами, подключёнными к собственному серверу; реальные секреты в архив не включаются.

Вариант с Яндекс Формами остаётся в генераторе как резервный, но не включён. Для выбранной схемы SMTP аккаунт Яндекса не нужен.

Проекты демонстрационные, юридические реквизиты ещё не заполнены. Локальная и GitHub-копии сохраняют `noindex`; основная SEO-сборка открывает 17 подготовленных страниц. Аналитика и рекламные кампании не подключены. Актуальный статус размещения — в `docs/deployment.md`.

Главная и форма предлагают начать с обсуждения потребности и помощи в формировании ТЗ. На главной отдельно представлены закупки по 44-ФЗ, 223-ФЗ и коммерческие закупки.

## Персональные данные и подготовка к рекламе

В `/privacy/` описаны права заявителя, сроки ответа и схема выбранного обработчика формы: SMTP на основном домене, FormSubmit в GitHub-копии. Аналитика по умолчанию выключена. Подготовлен загрузчик Метрики: с настоящим `METRICA_ID` появляется выбор посетителя; до согласия счётчик не загружается, отказ не мешает форме. Открытие информационного окна Cookie само по себе не даёт согласия.

До завершения политики и запуска привлечения заявок нужны:

- Реквизиты юридического лица или ИП — оператора данных и отдельный текст согласия на обработку.
- Утверждённые сроки хранения и фактический процесс удаления из почты, обработчика и резервных копий. Предложенные «3 года после обращения» пока не утверждены.
- Подтверждённая схема сбора и хранения в России вместо неподтверждённой инфраструктуры FormSubmit. Указание зарубежного сервиса в политике само по себе не решает вопрос локализации. Также нужно проверить размещение почты и необходимость уведомлений Роскомнадзора.
- Реальные разрешённые к публикации партнёрские документы. Неподтверждённые партнёрские статусы не добавляются.

Правовая проверка текста не подтверждает выполнение организационных процедур. На основном сайте работает собственный SMTP-обработчик; FormSubmit остаётся только в GitHub-копии. Включение индексации основной версии, подключение рекламы и юридическое завершение политики учитываются отдельно; актуальное состояние индексации записано в `docs/deployment.md`.

## Просмотр локально

Требуется Python 3.12 или новее.

```sh
python3 build.py
python3 verify.py
python3 -m http.server 4187 --bind 127.0.0.1 --directory dist
```

Откройте `http://127.0.0.1:4187/`.

## Публикация

GitHub Actions публикует сайт на GitHub Pages при каждом push в `main`. В Settings → Pages выбран источник GitHub Actions. Workflow получает адрес и префикс из настроек Pages: ссылки работают как по адресу проекта, так и после подключения собственного домена.

- `build.py`: содержимое и генератор страниц.
- `site.json`: основные сведения и обработчик формы.
- `dist/`: локальный сайт, стили, JavaScript и статические ресурсы.
- `verify.py`: заголовки, метаданные, ссылки и якоря.
- `.github/workflows/pages.yml`: автоматическая сборка и публикация.

Пример отдельной сборки для адреса проекта:

```sh
OUTPUT_DIR=_site BASE_PATH=/ligus-msk SITE_URL=https://aleshaio.github.io/ligus-msk python3 build.py
OUTPUT_DIR=_site BASE_PATH=/ligus-msk python3 verify.py
```

## Домен

Домен направлен на REG.RU. HTTPS проверен; HTTP и www перенаправляются на https://ligus-msk.ru с кодом 308. MX, SPF, DKIM и другие записи почты при загрузке сайта не менялись.

## Графика

Логотип — самостоятельный SVG с прозрачным фоном, нарисованными кириллическими буквами и сквозными каналами. Он выполнен по типографическому референсу заказчика, в ультрамарине и без знака TM. Иллюстрации оборудования и первого экрана созданы с помощью ImageGen. Фотография оборудования иллюстративная и не подтверждает ассортимент или включение моделей в реестр.

Обложка для ссылок находится в `dist/og.png`. Общие Open Graph и Twitter Card метаданные добавляются генератором на все страницы; заголовок и описание соответствуют каждой странице. Абсолютный адрес изображения строится из `SITE_URL`, размеры считываются из PNG, а хеш файла в URL обновляет адрес при замене обложки. Для новой обложки замените PNG и запустите сборку. В `robots.txt` разрешён обход страниц, чтобы роботы могли прочитать директивы `noindex`. Включение индексации управляется `INDEXING_ENABLED`; по умолчанию она выключена.

Шрифт Manrope используется по SIL Open Font License, копия лицензии находится в `dist/assets/OFL-Manrope.txt`.

## SEO и реклама — подготовлено, не запущено

[Пакет подключения](marketing/START.md): карта метаданных, три рекламных набора с 12 группами, 71 фразой, 48 заголовками и 36 текстами, TSV для Коммандера, цели и UTM. Подробный статус — в этом документе. Аккаунты, ставки и бюджет пока не настроены.

- `seo.py`, `marketing/seo-pages.json`: canonical, микроразметка, управление индексацией и sitemap.
- `dist/analytics.js`: выбор аналитики и цели без передачи полей заявки.
- `scripts/prepare_marketing.py`: проверка и экспорт рекламных черновиков.
- `scripts/check_marketing.mjs`: браузерная проверка с тестовыми ответами аналитики и SMTP.

Сборка с `INDEXING_ENABLED=1` открывает только 17 подготовленных страниц основного домена. GitHub-копия, служебные страницы и демонстрационные проекты не индексируются. Без `METRICA_ID` нет запросов к Метрике. Для повторной публикации основной SEO-версии используйте `INDEXING_ENABLED=1 python3 scripts/build_hosting.py --layout regru`. Метрика подключается независимо и пока выключена.
