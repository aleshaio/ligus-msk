# Подключение Яндекс Форм

Статус: код встраивания подготовлен. Форма в аккаунте Яндекса не создана, публичная ссылка отсутствует, доставка не проверена. В опубликованной версии продолжает работать FormSubmit.

## Настроить форму в аккаунте владельца

Название: «Лигус — подбор оборудования».

Описание: «Расскажите, какую задачу нужно решить. Поможем выбрать оборудование, сформировать ТЗ и подготовить предложение. Готовое техническое задание не требуется».

| Поле | Тип | Обязательное |
| --- | --- | --- |
| Как к вам обращаться | Короткий текст | Да |
| Телефон | Телефон | Да |
| Организация | Короткий текст | Нет |
| Электронная почта | Почта | Нет |
| Ваша задача | Длинный текст | Нет |
| Прикрепить файл — если есть | Файл, один файл | Нет |
| Согласие на обработку данных | Один обязательный вариант без выбора по умолчанию | Да |

Подсказка к задаче: «Для каких задач нужна техника? Что хотите оснастить, какой бюджет и сроки?».

Окончательный текст отдельного согласия и сведения об операторе нужно заполнить после получения реквизитов. Ссылка на текущую информацию: https://aleshaio.github.io/ligus-msk/privacy/. Не представлять её как завершённое юридическое согласие.

## Почтовое уведомление

- Получатель: `tender@ligus-msk.ru`.
- Тема: «Лигус — новая заявка с сайта».
- Тело: все ответы заявителя и ссылка на ответ в кабинете, если соответствующая переменная доступна.
- Обратный адрес: значение поля электронной почты, только если заполнено.
- Для отправки самого вложения включить прикрепление файла из соответствующего вопроса.

В Яндекс Формах общий размер почтового уведомления ограничен 9 МБ, включая текст и служебные данные. Для варианта с вложением в письмо установить ограничение загрузки 5 МБ и проверить доставку файла предельного размера. Для файлов больше этого предела использовать ссылку из уведомления, если это позволяет выбранная интеграция; сначала проверить доступ получателя. Не обещать прежние 10 МБ вложения в письме без проверки.

## Встраивание

1. Опубликовать форму для внешних посетителей и получить ссылку `https://forms.yandex.ru/u/<id>/` либо `https://forms.yandex.ru/cloud/<id>/`.
2. В `site.json` установить `formProvider: "yandex"` и записать ссылку в `yandexFormUrl`.
3. Запустить `python3 build.py` и `python3 verify.py`.
4. Проверить главную и `/request/` на телефоне и компьютере. Внешний вид полей определяется Яндексом; сайт задаёт ширину, высоту и светлую тему iframe. Высоту `.yandex-form-frame` уточнить по реальной форме.
5. Отдельно проверить внешний доступ без аккаунта, обязательные поля, необязательность вложения, успешную отправку и доставку письма с файлом. Публиковать переключение только после этих проверок.
6. Обновить этот статус и README; удалить неиспользуемые параметры FormSubmit после завершения перехода.

Одна ссылка используется на главной и странице заявки. При выборе Яндекса генератор также обновляет описание сервиса в разделе персональных данных и окне Cookie. При пустой или недопустимой ссылке сборка останавливается. Параметры категорий из старой формы не передаются в Яндекс автоматически: это отдельно настраивается по фактическим идентификаторам вопросов.

## Размещение данных

Замена обработчика не переносит GitHub Pages и не подтверждает отсутствие трансграничной передачи во всей цепочке. Перед сбором реальных заявок нужно проверить условия выбранного продукта Яндекса, размещение почты, сроки хранения и реквизиты оператора. Не добавлять в политику неподтверждённые гарантии географии обработки.
