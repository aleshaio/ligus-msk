- Собственный обработчик и библиотека: `/private/contact/`, за пределами `/www/`. Доступ к приватной папке — `700`.
- Резервная копия прежней стартовой страницы: `/ligus-backups/2026-09-17/site/`; отдельно сохранён `index.html`. Папка резервных копий закрыта правами `700`.
- При первом размещении версия загружалась в промежуточную папку, каждый файл был прочитан обратно и проверен по SHA-256. Затем папка сайта была заменена переименованием.
- Обновление SEO от 19 сентября: предыдущие версии 30 изменённых файлов сохранены в `/ligus-backups/2026-09-19-seo-032229/`. Новые файлы проверены в промежуточной папке и по одному заменены переименованием; контрольные суммы опубликованных файлов проверены повторно. Приватная конфигурация SMTP, PHP-обработчик и настройки сервера не заменялись.
- Сборка основной версии с открытой индексацией и выключенной Метрикой: `INDEXING_ENABLED=1 METRICA_ID='' python3 scripts/build_hosting.py --layout regru` → `release/ligus-regru.zip`. Без `INDEXING_ENABLED=1` сборка сохраняет `noindex`; это значение нужно указывать при последующих публикациях основной версии.
- `.htaccess` задаёт `index.html`, пользовательскую страницу 404 и перенаправляет HTTP и `www` на `https://ligus-msk.ru` с кодом 308, сохраняя путь и параметры. Путь проверки ACME исключён из перенаправлений. Предыдущая конфигурация сохранена в `/ligus-backups/2026-09-17/htaccess-before-smtp`.

- Главная, заявка, контакты, раздел ноутбуков: HTTP 200 и точное совпадение с локальными HTML.

- Неверный адрес: HTTP 404 с оформленной страницей сайта.

- PHP **8.3.31**, все нужные расширения (`openssl`, `mbstring`, `fileinfo`, `pdo_sqlite`, `zip`) включены. Загрузка до 10 МБ, тело запроса до 12 МБ.
