# Размещение Лигус — 17 сентября 2026

Сайт загружен на предоставленный REG.RU-хостинг и проверен по **https://ligus-msk.ru/**. DNS домена и `www` указывает на сервер хостинга. Почтовые MX-записи указывают на Mail.ru; при публикации сайта они не менялись.

## Файлы и повторная сборка

- Корень сайта в FTP: `/www/ligus-msk.ru/`.
- Собственный обработчик и библиотека: `/private/contact/`, за пределами `/www/`. Доступ к приватной папке — `700`.
- Резервная копия прежней стартовой страницы: `/ligus-backups/2026-09-17/site/`; отдельно сохранён `index.html`. Папка резервных копий закрыта правами `700`.
- Новая версия сначала загружалась в промежуточную папку, каждый файл прочитан обратно и проверен по SHA-256. Затем папка сайта заменена переименованием.
- Сборка для этой структуры: `python3 scripts/build_hosting.py --layout regru` → `release/ligus-regru.zip`.
- `.htaccess` задаёт `index.html`, пользовательскую страницу 404 и перенаправляет HTTP и `www` на `https://ligus-msk.ru` с кодом 308, сохраняя путь и параметры. Путь проверки ACME исключён из перенаправлений. Предыдущая конфигурация сохранена в `/ligus-backups/2026-09-17/htaccess-before-smtp`.

## Что проверено на сервере

- Главная, заявка, контакты, раздел ноутбуков: HTTP 200 и точное совпадение с локальными HTML.
- Логотип, JavaScript и OG-изображение: HTTP 200 и совпадение контрольных сумм.
- Неверный адрес: HTTP 404 с оформленной страницей сайта.
- Приватная конфигурация недоступна через адрес сайта: HTTP 404.
- PHP **8.3.31**, все нужные расширения (`openssl`, `mbstring`, `fileinfo`, `pdo_sqlite`, `zip`) включены. Загрузка до 10 МБ, тело запроса до 12 МБ.
- Обработчик включён. Конфигурация `/private/contact/config.php` имеет права `600`; папка `runtime` — `700`, база технических состояний — `600`.
- SMTP: `smtp.mail.ru:465`, SSL/TLS с проверкой сертификата. Отправитель и получатель — `tender@ligus-msk.ru`. Пароль приложения хранится только в приватной конфигурации на сервере.
- Тест через публичный `/api/contact.php`: токен получен, заявка с `ligus-smtp-test.txt` принята SMTP-сервером; ID `49da854cb736266a6b6159dd8a78ecb1`. Пользователь подтвердил получение письма и вложения 17 сентября 2026. После отправки временного файла в `runtime` нет.
- HTTPS проходит проверку доверия. Форма открывается по HTTPS, HTTP и `www` перенаправляются на разрешённый обработчиком origin.
- Главная просмотрена в браузере: изображения, шрифт и навигация отображаются.

## Что остаётся

1. **Плановая очистка.** Очистка технических состояний запускается при обращениях к обработчику; временный файл удаляется после каждой отправки. Отдельный запуск `maintenance.php` каждые 15 минут через планировщик хостинга пока не настроен.
2. **Публикационные сведения.** `noindex` и демонстрационные кейсы сохранены; юридические реквизиты и окончательная политика требуют данных компании.

GitHub Pages продолжает обслуживать отдельную статическую копию с FormSubmit. Автоматической FTP-публикации и хранения FTP-пароля в GitHub нет. Последующие изменения на REG.RU нужно загружать отдельно. Пароли в репозитории и этой инструкции не хранятся.
